# 2025class5.github.io

[English](README.md) | 简体中文

提供播放、进度与音量控制的静态浏览器音乐播放器。

## 项目概述

页面提供响应式单页音频播放界面，无需应用后端。首页移除班级合影与个人署名。

## 技术栈与依赖

HTML、CSS、JavaScript 与浏览器音频接口。可选用 Python 3 提供本地静态服务，音频资源与页面一同存放。

## 文件结构

- `index.html` — 播放器首页
- `music.html` — 另一播放器页面
- `music.mp3` — 音频资源
- `.github/` — 托管工作流

## 快速上手

在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/`，无需前端编译。外部托管资源需要网络。

点击播放按钮，拖动进度并调整音量。浏览器自动播放策略可能要求先进行一次用户操作。
